The completed **infrastructure evidence belongs in the shared Infrastructure repository**, including the BIND build, Route 53 delegation, victim/Unbound path and authoritative smoke tests.

This folder should later preserve structured non-image evidence such as:

- baseline/tuning notes;
- Detection v1.0 acceptance record;
- official operator UTC start/end and ground-truth summary;
- saved detection/alert result exports where useful;
- AI payload/output comparison;
- SOC timeline / 5W1H / disposition;
- SOC → IR handoff;
- IR decision and response rationale;
- containment/no-containment verification;
- safe reset;
- ground-truth comparison;
- lessons learned.

Evidence should prove the chain rather than preserve every terminal command or navigation issue.
